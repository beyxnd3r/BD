# Система учета интернет-трафика провайдера

## Описание проекта

Данная база данных предназначена для автоматизации учета интернет-трафика интернет-провайдера.

Система хранит:
- информацию об абонентах;
- тарифные планы;
- интернет-сессии;
- устройства пользователей;
- платежи;
- уведомления;
- обращения в поддержку.

База данных позволяет:
- анализировать использование интернет-трафика;
- отслеживать платежи;
- контролировать активность абонентов;
- получать аналитические отчеты.

## Используемая СУБД

PostgreSQL

## Структура базы данных

База данных содержит следующие таблицы:
- subscribers — абоненты провайдера;
- tariff_plans — тарифные планы;
- subscriber_plans — подключенные тарифы;
- devices — устройства абонентов;
- internet_sessions — интернет-сессии;
- payments — платежи;
- traffic_alerts — уведомления;
- support_tickets — обращения в поддержку.

## Основные возможности

Система позволяет:
- хранить информацию об абонентах;
- учитывать интернет-трафик;
- хранить данные об устройствах;
- отслеживать платежи;
- анализировать использование услуг;
- выполнять аналитические SQL-запросы.

## Используемые технологии

- PostgreSQL
- SQL
- DBeaver
- VS Code + SQLTools

## Ограничения целостности данных

В базе данных используются ограничения:
- PRIMARY KEY — для уникальной идентификации записей;
- FOREIGN KEY — для связи таблиц;
- NOT NULL — для обязательных полей;
- UNIQUE — для уникальных значений;
- CHECK — для проверки допустимых значений.

## Индексы

Для ускорения выполнения запросов были созданы индексы:
- idx_subscribers_phone;
- idx_sessions_subscriber;
- idx_payments_subscriber.
